# 假装无敌 - 指示线编辑器

指示线编辑器是可以让玩家在游戏内，将素材放入指定位置后，调整参数，即可播放对应的指示线，编辑器内的预览，如果点击次数为8的倍数则玩家指向全场武将，如果是9的倍数，则全场武将指向玩家，支持以下参数

1. 特效名称 (label): 显示在页面上的名称。

2. 骨骼名称 (name): 读取骨骼/图片的名称，不需要后缀。

3. 骨骼动画 (action): 当指示线类型为移动时，会读取骨骼标签；当指示线类型为拉伸时，将会消失。

4. 指示线类型为移动：使用红色字体表示，对应的值为2。移动就是读取骨骼，播放骨骼的指示线（例如十周年、OL、皮肤指示线）。 

5. 指示线类型为拉伸：使用红色字体表示，对应的值为1。拉伸就是将一张图片拉伸到对面（例如手杀的指示线）。 

6. 指示线类型 (lineType): 有两个值选项。 
   - 移动(2)。移动就是读取骨骼，播放骨骼的指示线（十周年、OL、皮肤指示线）。
   - 拉伸(1)。拉伸就是将一张图片拉伸到对面（手杀的指示线）。

7. 开启触发时机(enableTrigger): 开启触发时机时，将会在对应的时机触发。

8. 触发时机(trigger): 触发时机参考技能的trigger，在对应的时机触发指示线

9. 过滤(filter): 过滤方法，要播放这个指示线的时候执行，拥有以下参数，需要一定技能的代码基础

   - trigger: 当前触发的事件(参考技能content里面的trigger)

   - player: 当前触发事件的玩家

   - event: 当前触发的事件(参考技能content里面的event)

   - start: 指示线开始的位置(一般是player)

   - end: 指示线结束的位置

   - 以下是一个参考示例：爆伤指示线

     ```javascript
     function filter(trigger, player, event, start, end) {
         if (trigger.num < 2) return false;
         if (trigger.player === player) return false;
         return true;
     }
     ```

10. 开始位置(startPosition): 指示线开始的地方（只有开启了触发时机才可以填写，必填，需要一定的技能基础）

    - 例：参考爆伤指示线

      ```javascript
      trigger.player
      ```

11. 结束位置(endPosition): 指示线结束的地方，参考**开始位置**

12. 皮肤指示线(skillLine): 因为皮肤指示线比较特殊点，所以单独开了个选项，如果是皮肤指示线，请开启此选项，不然开始和结束位置不准

13. 是否循环(loop): 当选择**皮肤指示线**后，此选项呢不可用，将会消失，**用于指示线类型为移动**，不然**骨骼移动到一半可能就会消失**了

14. 将牌区域(isPlayerCard): 玩家的指示线都是从屏幕中间，玩家手牌区上方出发的，并不是武将牌区域，开启此选项后，指示线将会从武将牌区域出发

15. X轴缩放(scaleX): 不做介绍

16. Y轴缩放(scaleY): 不做介绍

17. 移动时间(playTime): 指示线从开始位置移动到结束位置所需要的时间

18. 收尾时间(endTime): 仅在指示线类型为**拉伸展示**；指示线尾端移动到对面的时间

19. 到目标后悬停(hoverTime)：仅在指示线类型为**移动展示**；当指示线移动过去后，停留多长时间，一般搭配一条横线

20. 是否JSON骨骼(isJson): 不做介绍

21. 播放速度(speed): 不做介绍

22. 播放延迟(spine_delay): 不做介绍

23. 旋转角度(rotation): 不做介绍

24. 骨骼图层(zIndex): 这是在播放骨骼的图层，渲染多个骨骼时的图层，防止被其他特效覆盖，并不能调整canvas图层！！！！！

25. 是否懒加载(is_lazy): 不做介绍

26. 不透明度(alpha): 不做介绍

27. 播放完毕(completes): 当指示线播放完毕后触发的特效，一般用于皮肤指示线，当然也可以自定义，可以播放**特效编辑器里面的特效**也可以播放**指示线里面的指示线**，有以下参数

    - configId：配置ID

    - type:  类型，可选以下两个参数

      - animation
      - line

    - target: 播放位置，可选以下两个参数

      - start: 指示线开始的位置
      - end: 指示线结束的位置

      示例

      ```json
      [{
        "configId": "指示线/曹纯/shouji",
        "type": "animation",
        "target": "end"
      }]
      ```

28. 附加指示线(appendAnimation): 在播放指示线的时候同时播放其他指示线(无视开关，但是走filter)，填入**配置ID**

    - 示例：

      ```javascript
      ["指示线/OL指示线"]
      ```

29. 配置ID(configId): 用于播放附加**指示线**或者**播放完毕**
