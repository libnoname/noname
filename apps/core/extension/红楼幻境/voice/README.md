# 人物配音接入

本目录将通用播放逻辑、人物事件配置、台词资源清单与录音导入记录分开。配音不参与牌堆、技能数值、身份和游戏随机数运算；所有规则仍由原技能负责。

## 当前资源状态

用户提供的原始目录为 `theme/绛珠仙子_配音`。同一目录中的录音是同一句的不同演绎，全部接入；每次触发先随机选对应情境的台词，再从该句的演绎版本中等概率随机选一个。当前共139句、282个演绎版本。游戏文件统一为 `theme/voices/hlhj_daiyu/hlhj_daiyu_<台词编号小写>_<两位版本号>.mp3`，例如 `hlhj_daiyu_ts01_01.mp3`。版本号按原MP3文件名自然升序排列，不拼接、不转码，原文件全部保留。

文件夹对应台词的依据在 `import/hlhj_daiyu.json`。`import/hlhj_daiyu-selected.json` 沿用原清单文件名，现记录全部已接入演绎的版本号、原文件、规范文件名和 SHA-256，`mode` 为 `random-variants`。所有组的映射均已确认，`pendingGroups` 为空；`missing` 表示没有对应录音的文稿编号，不影响同组其他台词使用。

按用户确认：`4ZH/49` 新补录音对应ZH10，40至51依次对应ZH01至ZH12；`5XX` 忽略53，51→XX01、52→XX02、54→XX03，随后依次至61→XX10，XX11暂缺对应录音；`6GM` 忽略71，61至70对应GM01至GM10，72→GM11、73→GM12、74→GM13。运行时自动跳过未提供的XX11，不挪用其他台词或字幕。

## 对局行为

- 顶部「红楼配音」或扩展设置打开配音面板。桌面端左侧为播放设置，右侧为台词音册；小屏上下排列。墨绿、暖金配色与统一控件，限制面板尺寸，避免全屏空白。总开关、技能／生命周期／外观分类开关、音量百分比、字幕和外观配音间隔即时保存，仅对本机生效。
- 台词音册支持按人物、技能情境筛选，按台词全文、编号和情境搜索，每页16句。每句完整展示字幕、编号及情境，提供“随机演绎”与每个具体版本的选择、逐句播放／重播、单句停止、播放进度和时间显示。可随机试听当前筛选结果；“停止试听”仅停止本面板发起的声音，“停止全部配音”才停止所有本扩展语音。关闭面板停止其试听，保留正在进行的对局配音。
- 试听独立于对局配音开关，但遵循音量设置；仅在本机播放，不广播、不写入对局录像。指定版本加载失败时明确提示，可手动重试，不偷偷改播其他演绎。
- 默认启用全部分类与字幕，音量为本体音效音量的100%。原画、背景配音共用每人60秒的外观冷却，可改为0／15／30／60／120秒；不改变原画15秒轮换和背景随曲终切换的规则。
- 化情思、初结缘、为缘摸牌、自摸弃思、换缘、收弃牌、双方得牌、失花、葬花、潇湘得泪／失泪、归梦／授愿、遗愿回复／代伤、情思转移各自选用对应情境的台词。继承遗愿的其他武将仍使用赠予技能的绛珠仙子配音。
- 首次可见入场（开局首个回合前）、中途登场／亮将、受伤、濒死、死亡、自己对局的胜负均有对应事件。木石缘实际受到伤害后触发探伤台词；自己作为木石缘时只使用自身受伤台词。暗置武将不因配音暴露。
- 化情思涉及隐藏手牌，仅对持有者播放；其他公开技能由权威端选定台词和具体演绎文件并用本体广播发送，正常情况下各端播放同一版本，录像记录实际文件路径。外观和试听各端独立，胜负只按本机玩家结果播放。
- 台词按情境随机选取，并避免同一情境连续重复；选定台词后，每次从它的所有演绎版本中随机选一个，允许随机重复口吻。拥有更多演绎的台词不会因此提高被选中的概率。字幕始终取自对应台词编号。单个演绎损坏时尝试同句其他版本，不禁用整句台词。
- 各条配音独立、并行播放，新技能无需等待上一句，也不截断或替换其他配音。连锁子技能不再受主技能优先级抑制，技能语音不再使用时间冷却合并多次发动。外观及受伤等生命周期事件保留各自的冷却；通过冷却检查后同样并行播放。相同网络消息按消息ID去重，独立发动不会被当成重复投递。
- 字幕按触发顺序自上而下多行排列，实际开始播放时显示，结束后按先进先出移除。若后触发的短句先结束，其字幕会保留到排在前面的语音结束后一起出队；音频播放不受字幕队列影响。字幕区域限制高度并自动滚动至新字幕，不会无限覆盖对局。关闭字幕不会停止语音。
- 初次显示头像／背景不算切换；后续图片载入成功且确实发生切换才播报。死亡和结局不重置主题、原画计时或音乐。死亡后不再因死者的自动换画发声。
- 只要还有配音正在播放，黛玉主题音乐就保持临时压低到35%；全部结束或中止后才恢复，单句先结束不影响其他配音。使用本体原音乐时保持其原音量。
- 音频按需加载，不预载整套录音。每条语音各自管理音频、加载超时、错误恢复和字幕；浏览器禁止自动播放时，尚未超时的语音可由点击或按键恢复。资源错误只处理出错的这一条，不打断其他配音。页面隐藏、离开页面或点击“停止”会清理全部本扩展语音。多次试听也可并行，音量滑块同时更新所有正在播放的语音。

## 新增人物

1. 为人物编写独立事件配置，参照 `daiyu.js`；每个事件包含 `label`、`lines`、`category`，可附加 `cooldown`、`group` 和 `ttl`。`priority` 兼容保留但不再决定抢占、排队或抑制；技能分类忽略冷却，其他分类沿用设置。根目录、人物名、台词都由配置提供，公共控制器不含黛玉技能名。`isBond` 是可选的关系查询，不修改角色关系。
2. 为人物建立导入清单，包含 `character`、`source`、`document`、`folders`。文件夹到台词编号必须明确一一对应，同一目录内全部MP3均作为该句的演绎版本接入。文本表格沿用审核稿格式；如果采用其他格式，可直接提供静态 `clips` 清单：每句包含 `text` 与 `variants` 文件名数组。公共播放器仍兼容旧的单文件 `file` 字段，不要求其他人物同步迁移。
3. 从仓库根目录运行 `node scripts/import-hlhj-voices.mjs apps/core/extension/红楼幻境/voice/import/<人物ID>.json`。这是资源整理操作，不运行测试或构建。脚本生成全部演绎、字幕清单与开发客户端镜像；重复执行覆盖相同规范文件，仅清理上次清单记录且内容未被修改的过时生成文件，不移动或删除原录音。
4. 在扩展 `precontent` 中用同一个 `installVoiceRuntime` 返回值调用 `register(spec)`，并用 `voiceFiles(clip)` 展开各句的全部演绎加入扩展的 `files.audio`。保留唯一 `_hlhj_voice_events` 公共规则技能。
5. 在实际发动成功的位置调用 `game.hlhjVoice?.emit(player, characterId, eventName)`，每次独立创建播放任务。旧的 `scope` 接口保留为空操作，无须改动已有角色的调用，但也不再抑制连锁配音。隐藏信息使用 `{ private: true }`；外观使用 `{ local: true, event: false }`。已接入的技能设 `audio:false`，避免本体额外按技能名播放重复声音。
6. 外观控制器可用 `addMusicAdapter(factor => ...)` 注册临时音乐衰减，释放时调用返回的取消函数。人物之间共享播放管理，无需复制控制器或修改本体声音方法。

## 资源发布与版本移植

独立扩展使用 `extension/红楼幻境/theme/`，当前内置适配器使用 `image/hlhj/theme/`；传给人物配置的根目录来自扩展现有路径参数。没有绝对磁盘路径、在线TTS请求或浏览器目录枚举。

开发镜像和托管发布脚本排除以 `_配音` 结尾的原录音目录，仅发布规范资源。手动分发扩展时需带上 `extension.js`、`appearance.js`、`voice/runtime.js`、人物配置、`voice/catalogs` 及 `theme/voices`，不必带原录音、导入记录和开发脚本。原有卡图、背景、歌单等资源仍按扩展原发布清单携带。

对局播放通过本体 `game.playAudio` 的兼容字符串参数调用，公开事件用本体广播、录像沿用 `playAudio` 记录；面板试听使用独立的本地音频元素，仍参与公共音量、并行播放、音乐衰减与资源释放管理。面板和样式位于 `voice/panel.js`，随模块分发，不依赖本体皮肤或独立样式路径；移植和手动分发时需一并携带。不覆写本体的技能／死亡音频方法。此方案面向支持 ES 模块扩展、当前异步技能与标准玩家事件的版本，旧式 `game.import` 扩展格式仍需入口适配，不能据此宣称所有无名杀版本直接兼容。原有身份限制的本体适配要求未改变。

按用户要求，本次只进行源码修改和资源整理，没有运行游戏验证、测试、构建、打包或部署。
