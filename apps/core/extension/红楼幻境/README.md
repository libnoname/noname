## 身份限制

绛珠仙子不能分配为内奸。身份模式先分配身份、再选武将，因此本体在选将完成后、开局身份技能及发牌前落实此限制：若主将或副将为绛珠仙子且预分配身份为内奸，与一名非绛珠仙子的普通忠臣、反贼或平民随机交换身份，保留身份人数。主公、明忠和特殊身份席位不参与交换。3v3v2中的红、蓝内奸同样受限，只在相同颜色中与忠臣或野心家交换。自定义阵容若无可交换席位，则普通内奸改为反贼，红／蓝内奸改为同色忠臣，优先满足武将限制。隐藏身份仅向本人更新显示，最终身份纳入正常开局同步与录像。本规则属于选将限制，不因技能失效而解除，不追溯改变已经开始的对局。

此限制同时需要更新本体 `mode/identity.js` 与本扩展／内置武将包；只替换独立扩展文件而沿用旧本体不会执行开局身份修正。

## 黛玉风华：原画、背景与音乐

对局中黛玉首次亮明后，顶部显示「黛玉风华」入口，死亡后仍保留；独立扩展也可在扩展设置中打开「黛玉风华 · 原画 / 背景 / 音乐」。选择即时保存，不广播给其他玩家。

- **原画**：默认每15秒在「潇湘竹影」「绛珠归梦」间独立轮换，可配置6/12/15/20/30/60秒、固定原画或随泪数转换。旧版设置首次迁移到自动15秒，此后手动选择继续保存。「绛珠题笺」保留原始 SVG 立绘。减少动态效果仅取消过渡，不停用自动轮换。原画缓存异步解码，头像子节点被本体重建后会重新挂载覆盖层。
- **背景**：竹影晨雾和归梦月夜是两张独立画作。默认开局随机选择一套，每首曲目自然结束后换景；可保持当前背景、固定指定背景、使用原背景，或手动立即换景。原画变化不触发背景或音乐变化。
- **音乐**：「竹窗听雨」目录的两首MP3对应竹影，「绛珠归梦」目录的两首MP3和一首M4A对应归梦，不再播放旧WAV。支持顺序循环、每轮不重复的随机循环、下一首、原音乐、静音和主题音量。两份歌单分别记录本局进度；“下一首”只换曲，自然曲终才按背景设置换景。坏曲跳过，整份歌单失败恢复原音乐，点击播放可重试。服从本体音乐开关、静音和音量。
- **死亡与清理**：主题一经启用便保留到离开页面；黛玉死亡、离场和本局结算都不重置桌面、不打断音乐，歌单及轮换设置继续有效。页面隐藏时暂停音乐，返回恢复；离开页面或主动销毁控制器时释放资源。暗将不提前展示，托管服务端不初始化外观。
- **入场流畅度**：字体使用即时回退并提前加载已选字体；不再监听整个对局DOM的每次卡牌变化，只观察座位变化并定期轻量更新。入场先加载当前背景，其余背景按需加载，原画异步解码并复用缓存。情思牌面内缩3px并继承本体圆角，不裁切名称、点数、花标记和选中效果。

「固定竹影背景」「固定归梦背景」只设置背景及对应歌单，不修改人物原画。固定背景优先于开局选择；“开局背景”在下一局生效。本体音乐关闭或音量为零时需在声音设置中开启。

生成提示词和资源来源见 THEME-ART.md。开发与托管客户端使用 image/hlhj/theme 资源镜像，独立扩展使用 theme。增删或重命名音频后，在仓库根目录运行 `node scripts/sync-hlhj-theme.mjs`，从两个目录生成歌单并同步镜像；该脚本不执行测试或构建。正式联机构建会从扩展 theme 目录覆盖客户端资源。

## 情思与花

- 无论摸牌、获得他人牌、葬花、交换手牌还是直接发牌，基本牌与武器（equip1）进入黛玉手牌后均先转化为独立基本牌【情思】，保留花色和点数，不再作为原牌使用或打出。花标记不阻止转化。装备区内的武器，以及防具、坐骑、宝物和锦囊不转化。普通手牌转移、响应处理区移动不恢复原牌；进入弃牌堆或牌堆时，实体转化牌恢复原名、花色、点数和属性，保留实体牌ID。额外生成的牌在进入这两个区域时销毁，避免混入牌堆或在洗牌时改变构成。
- 情思不计入手牌上限，弃牌阶段不会因超出手牌上限被弃置；带花标记的情思同样如此。情思仍是实际手牌，可响应、转移或支付技能弃牌代价，不因此满足“空城”等无手牌条件。此规则随独立情思卡牌对持有者生效，归梦弃置全部手牌仍正常执行。
- 【情思】有独立牌面和目标转移效果。成为其他角色使用任意牌的目标时，只要有可打出的情思及存活且不是自己的木石缘，都会提供打出情思的选择，可以取消。保留原使用者和其他目标，不受原牌选目标范围限制；南蛮入侵、万箭齐发等多目标锦囊同样适用。木石缘已在目标列表中时，仍额外承受黛玉转移的一次效果，例如原本对双方各结算一次的南蛮入侵，转移后黛玉不结算、木石缘结算两次，而非合并为一次。情思没有主动出牌阶段效果，也可以被技能弃置。
- 不存在独立的“缘”卡牌。“木石”是角色关系标识；“花”是手牌标记。
- 葬花取得的原牌及复制牌均进入手牌，先结算绛珠仙子的情思转化，再添加“花”手牌标记。基本牌、武器因此成为带花标记的情思，只能按情思效果打出；锦囊、防具等未转化的牌则保留原效果，可正常使用或打出。花标记始终附加于转化后的牌，不还原原牌名。
- 花离手即失去花标记。任何时候失去花牌，立即获得等量泪；使用、打出、弃置、交出、装备、埋葬或移至其他区域均计数，不再等到回合结束。计数读取每次实际失牌时保存的花标记，转移、批量失牌的子事件也计入，同一次失去不会因父事件再次计数。进入弃牌堆后销毁的复制花仍计数；花标记已经消失的牌以后再次移动不重复得泪。手中剩余的花保留，不自动清空。已开始绛珠归梦结算后不再递归获得泪。
- 其他角色弃牌后，黛玉选择其中仍在弃牌堆的一张：本回合第N次发动时，黛玉获得原牌及N−1张复制牌，存活且不为自己的木石缘获得N张同名、同花色、同点数、同属性的复制牌。木石缘所获牌不附加黛玉的花标记；所有复制牌进入牌堆或弃牌堆时销毁，不增加牌堆构成。木石缘是自己时不重复发牌，木石缘不在场时黛玉照常获得。
- 黛玉第1、2、3…次葬花仍分别获得1、2、3…张花，取消不递增；次数于每个角色回合开始重置。复制牌进入弃牌堆或牌堆时销毁，不会在响应处理区、装备区或判定区提前消失。

## 葬花吟

自己的出牌阶段可主动发动，每次选择任意数量的花牌（至少一张），将它们置入弃牌堆，并由香断谁怜立即获得等量泪。发动次数不限，可以取消；带花标记的情思也能埋葬。埋葬不增加香断谁怜收取弃牌时的葬花次数。获得泪后照常结算木石前缘的可选摸牌及绛珠归梦阈值。

## 木石前缘

游戏开始必须选择一名角色为木石缘，不限性别，可以选择自己。木石缘的武将区域显示“木石”标识，查看标识可见与谁结缘；多个黛玉可以分别与同一角色结缘。

自己的回合开始时，可以选择一张可弃置的情思和一名不同于当前木石缘的角色。支付弃牌代价后更换关系；取消不弃牌、不更换。旧木石缘去除对应标识，新木石缘添加标识；其他黛玉的关系不受影响。

每次获得泪后，可选择自己或存活的木石缘摸等量牌，也可取消。选择自己时先摸牌，再弃置一张可弃置的情思；如果摸牌后仍没有可弃置的情思，则无牌可弃。木石缘死亡后，可以在自己的下个回合开始时重新指定。

支付上述弃牌代价期间，弃花仍正常得泪并检查绛珠归梦，但得泪不再触发木石前缘摸牌。防重入仅在这名黛玉支付代价期间生效，结算结束或异常时立即解除；不增加每回合次数限制，不限制其他角色，也不影响之后正常失花得泪、摸牌。长形卡牌布局中，情思牌面固定四边内缩3px，覆盖本体针对方形插画的8px下移，消除上沿拼接线。

## 潇湘妃子

木石缘与其他角色发生牌的获得转移，或成为其他角色红色用牌的目标时，可以获得泪。每个角色回合内实际发动依次获得1、2、3…枚。取消不递增；同次红色用牌只询问一次，普通从牌堆摸牌不计。

牌转移匹配同一移动过程中的实际失牌和得牌，包含批量分牌的子事件、交换手牌，以及从判定区或武将牌上取得的牌；批量转移及换手牌统一在完成时询问，避免子事件重复询问。红牌在目标调整完成后的 useCardToTargeted 时机判断，按使用者计算颜色；得泪提示显示本次触发原因。

木石缘以黛玉为用牌目标时仍须失泪，依次为1、2、3…枚，最低0；只有实际失泪才增加下次失泪量。得泪、失泪、葬花各自独立计数，每个角色回合开始重置。

## 绛珠归梦与遗愿

达到 max(8, 场上存活角色数 × 2) 枚泪时，完成本次得泪相关的可选摸牌及自摸弃情思结算，随后强制弃置全部手牌并直接死亡，不通过濒死求桃。人数下降时也检查阈值。

黛玉死亡前，可令当时存活的木石缘永久获得绛珠遗愿，也可取消；不是强制授予。

绛珠遗愿：受到伤害后，若仍存活，回复1点体力。每个角色回合一次，可代替其他角色承受一次伤害；拒绝不消耗次数。保留来源、数值和属性，一次伤害不重复转移。致命伤害仍须先通过濒死结算。
