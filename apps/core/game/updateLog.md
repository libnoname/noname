# 扩展适配

- 覆盖`useCard`事件或修改其结算流程的扩展，需跟进本次动画与追加结算流程的调整；追加牌效果可结合`useCardEffectEnd`和`effectCount`处理。
- 使用装备栏批量操作的扩展，可通过`disableEquip`、`enableEquip`的对象参数传入`slots`和`all: true`，处理指定类型的全部可废除或可恢复栏位。
- 自定义帮助页面现在按需挂载。`mount`可返回同步清理函数；Vue帮助组件可设置`persist: false`，在切换离开时卸载。
- 直接复用或覆盖本次调整武将技能的扩展，需跟进技能标记、蓄力点及结算流程的变化。
