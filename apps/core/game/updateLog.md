# 扩展适配

- 修改过`Content#lose`的扩展，需跟进转化延时锦囊与卡牌销毁流程的调整。
- 修改过`Player#mark`或`game.over`的扩展，需跟进转化技标记和联机胜负结算手牌查看流程的调整。
- 修改过`Content#showCards`的扩展，需兼容`customButton`回调新增的事件参数。
