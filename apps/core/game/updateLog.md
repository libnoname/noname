# BUG修复

## 武将技能

- 修复李昭仪【娴辅】的换牌流程，改为双方同时选择至多三张手牌进行交换，并避免取消交换或额外调整牌序。
- 修复【持剑】视为拥有的青釭剑不提供攻击范围，以及【震弓】可对已选择目标反复叠加伤害的问题。
- 修复傅干【巧谏】在联机模式中的弃牌交互和结算异常，并使双方发动时至少弃置一张牌。
- 修复OL薛灵芸【思泣】在联机客机处可能卡死、手杀清河公主【谮构】在插入结算时可能报错，以及【逆涡】发动后可能报错的问题。
- 修复手杀灵雎【焚心】在部分模式中无法正常获得技能，以及幻曹冲【修睦】、夏侯紫萼【血偿】等技能的AI选择问题。
- 修复裴秀【茂著】无法选择已进入地图的地图技能，以及陆绩失去【怀橘】后“橘”标记未一并移除的问题。
- 修复势邓艾【屯田】、势陆郁生相关技能的失牌检测，并修正四象封印司马昭【昭心】的触发条件和效果。
- 修复手杀孔融【礼让】无法正常获得弃牌或清除“谦”标记、【慑伏】可能由无关角色误触发，以及【二圣】在其他角色回合结束时错误发动的问题。
- 修复【戎弁】获得技能时覆盖已有附加技能、【合援】在没有【镇围】记录时仍可能弃牌，以及【慨公】未正确无视距离检查用牌目标的问题。
- 修复【驰原】连续红色牌计数、【期期】判定时机、【世公】切换武将时机、【珏珏】使用【酒】时错误增加伤害，以及【岁祟】准备阶段无法取消的问题。
- 修复卫青【北进】的确认、永久失去体力效果和触发时机，并修复经典孙策【双璧】、哪吒【法器】强制选择或缺少结果校验的问题。
- 修复新杀谋关羽死亡后【倨傲】效果可能残留、魔魏延【竭伐】可能报错，以及OL界程普【疠火】重复询问的问题。
- 修复势曹真【伺锋】相关牌信息可能被目标看到、十常侍【庀材】可能无限判定、幻法正【弈势】可能报错等技能异常。
- 修复星张昭【忠言】交换过程中可以取消或额外调整牌序的问题。
- 修复界钟会【排异】弃置“权”尚未完成便继续结算，导致摸牌数量与提示不符的问题。
- 将【百变】修正为非锁定技，并补充手杀曹嵩【亿金】的负面技能AI标签和【乱群】的确认交互。
