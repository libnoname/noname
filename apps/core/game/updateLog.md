# 主要更新

## 界面与模式

- 重做胜负结算页面的手牌查看入口，可在角色数据统计界面查看各角色剩余手牌，并优化相关手牌容器的布局和显示效果。
- 调整南华老仙【青书】的选择界面，使选项更便于点击和查阅。
- 调整点将单挑模式：开启单人控制时，胜负结算默认以玩家阵营判断胜利。
- 调整国战OL专属分包为“他山之石”，移除其中技能未发生变化的限时武将。
- 更新国战钟会【排异】【邀叛】和国战吴懿【转征】至新版结算。
- 修复部分布局中当前角色手牌数偏移，以及“看破”按钮可能异常残留的问题。
- 将新手教程中的社区入口由贴吧调整为GitHub仓库。

## 武将与卡牌

- 新增“契定技”技能标签、提示和标记样式，并增加`get.is.qidingSkill`与`awakenQidingSkill`以支持契定技的动态判定和状态切换。
- 翻修“蚀心入魔·嗔”武将包，并调整魔吕布【夺炁】、周宣【寤寐】、爪黄飞电【先行】等技能。
- 更新手杀钟繇、手杀兀突骨、手杀程昱、手杀界张嶷、手杀薛综、手杀界严颜，以及谋孙权、谋徐盛、新杀神曹丕等武将的技能或数值。
- 更新OL曹金玉、OL谋贾诩、OL谋程昱、OL界辛宪英、OL界曹节、OL孙鲁育、OL韩馥等武将的技能。
- 更新势孙峻、势国渊、势桓阶、星夏侯霸、环怀瑾、幻大乔等武将的技能、描述或结算。
- 修复【贯石斧】弃牌后效果不生效、【雌雄双股剑】结算缺失、【刮骨疗毒】结算异常，以及【五谷丰登】相关流程判断错误的问题。
- 补充并调整多名武将的原画、语音、台词、称号和技能提示。

## 底层与工程

- 将所有卡牌包及《始计篇》武将包中的`Step Content`重写为异步内容，并将《始计篇》加入编译队列。
- 重构`chooseCardOL`和`chooseButtonOL`，异步化相关联机选择流程。
- 统一`gain`、`addToExpansion`、`gaincardMultiple`和`addToExpansionMultiple`事件的动画处理，并支持传入返回`Promise<void>`的自定义动画函数。
- 重构`useCard`事件对`useCardToPlayer`、`useCardToTarget`、`useCardToPlayered`和`useCardToTargeted`子事件的处理，优化目标排序及动态增减目标时的流程。
- 重构`lib.filter`、`get.filter`、`get.min`和`get.max`等函数，补全相关JSDoc、函数签名和Mod类型提示。
- 修复`game.finishSkill`处理`inherit`和`viewAs`时使用浅拷贝，可能导致技能数据相互污染的问题。
- 修复`cardEnabled`未正确将传入的`Card`或`CardBaseUIData`转换为`VCard`的问题。
- 将线下武将包的技能文件按分包拆分，降低单文件规模并改善后续维护。
- 拆分联机服务端，将运行入口与库入口分离，使服务端既可独立运行，也可作为库引用。
- 为移动端实现基于Android SAF的可写文件覆盖层：APK资源作为只读基础层，用户文件和扩展内容可在外部目录中覆盖同路径资源。
- 修复检测加密扩展时相关配置不生效的问题。

# 扩展适配

- 修改过`get.nodeintro`的扩展需适配本次手牌查看界面的调整。
- 修改过`gain`、`addToExpansion`、`gaincardMultiple`或`addToExpansionMultiple`事件的扩展，需兼容动画函数返回`Promise<void>`的情况。
- 修改过`Content#disableEquip`的扩展，需跟进复合坐骑栏中`discardingCards`的筛选逻辑。
- 使用【火攻】或【闪电箭】相关`chooseToDiscard`流程的扩展，请将`discardPostion`修正为`discardPosition`。
- 使用魔吕布【夺炁】、周宣【寤寐】或爪黄飞电【先行】相关实现的扩展，需跟进本版本的技能调整。
