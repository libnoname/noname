## 发行包部署

部署工具服务于本次已核对基线的本地发行包，不是任意版本的通用升级器。

```powershell
$env:OWNED_MARK_RELEASE = 'C:/Users/32360/Desktop/无名杀-win32-x64/resources/app'
$env:OWNED_MARK_RESULTS = 'C:/Users/32360/Desktop/无名杀-win32-x64/audit/mark-ownership-implementation'
node tools/deploy-owned-marks.mjs
node tools/deploy-owned-marks.mjs --apply
```

需要 TypeScript 和 esbuild；可用 OWNED_MARK_ESBUILD 指定 esbuild 的模块目录。无参数只计算并校验计划。应用前完整生成输出、检查语法与源码成员冲突，逐文件备份，输出 deployment.json 的前后 SHA256。更新时验证上次部署后的文件未被外部修改；重用最初备份计算增量，保留发行包中无关本地修改。备份目录必须和 deployment.json 一起保存。它不写入用户存档或扩展目录。

标准完整 pnpm build 会重建既有 dist；此次没有覆盖开发端已有 dist。本次用有备份的选择性编译更新实际加载的发行模块，编译目标与项目一致：chrome91 / safari16.4。

## 实际加载模块的浏览器测试

```powershell
$env:OWNED_MARK_RELEASE = 'C:/Users/32360/Desktop/无名杀-win32-x64/resources/app'
$env:OWNED_MARK_RESULTS = 'C:/Users/32360/Desktop/无名杀-win32-x64/audit/mark-ownership-implementation'
node tools/test-owned-marks-browser.mjs
```

此本地工具默认使用上述发行目录、已安装 Chrome，以及发行包 tmp_diag 中的 playwright-core。只读临时 HTTP 服务器绑定随机端口，使用新浏览器 context，不启动会固定使用正式用户数据目录的 Electron 主程序，不写正式存档。测试加载实际 Player、GameEvent、武将与模式模块；网络测试使用双 context、原生 WebSocket、自建临时 RFC6455 转发器和真实 Client 编解码链。它不是完整联机大厅测试；调用真实录像恢复 handler 也不是整段录像播放器测试。

OWNED_MARK_RESULTS 是结果目录。浏览器单独指定结果文件时使用 OWNED_MARK_BROWSER_RESULTS。运行结果中的失败会导致非零退出；保留 scope、assertions、pageErrors、writes 与实际请求路径，避免把未加载的代码误当作已验证。
