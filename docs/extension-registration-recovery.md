# 原有扩展入口恢复（2026-09-09）

## 排查结果

- `名将杀`、`活动武将`等原有扩展的文件仍在源目录和已有构建目录中。`git diff --exit-code HEAD -- apps/core/extension` 通过：原有受 Git 跟踪的扩展文件没有修改或删除。
- 自动登记逻辑此前只处理整理归档清单，遗漏了 7 个原有手工安装的扩展。它们依赖浏览器已有登记或“自动导入扩展”开关，缺少登记时不会出现在扩展菜单中。此问题可以在不含这些登记的配置中复现；不能据此推断用户当前浏览器存档的全部历史变化。
- 上次添加资源把校验版本从 2 提高至 3，旧逻辑遇到版本变化会重新关闭整个安全名单，可能覆盖用户后来手动启用的旧扩展。

## 修复边界

- 新增 `apps/core/game/bundled-extensions.json`，补齐“名将杀”“活动武将”“3D精选”“杀海拾遗”“欢乐卡牌”“玩点论杀”“英雄杀”的首次自动登记。
- 扩展列表仅追加，保留已有顺序和自定义扩展；保留所有已有开关、扩展私有选项、武将包设置。
- 尚无开关记录的原有手工扩展默认关闭，避免在新存档中意外同时执行全部扩展；已有启用记录继续启用。
- 校验版本变化不再重置旧开关。新 APK 扩展仍按此前设置默认关闭。
- 不覆盖原有扩展代码、素材，不清空浏览器数据，不强制启用缺依赖的旧包。

## 使用

在原先使用的浏览器和访问地址重启游戏，再打开“扩展”菜单。不要切换 `localhost` / `127.0.0.1`、端口或浏览器来找旧存档，这些可能对应不同存储空间。

如“名将杀”显示关闭，可在菜单中启用后重启。若旧迁移已经关闭某个包且没有备份，程序无法区分“迁移关闭”与“用户主动关闭”，因此不能无依据把全部旧包强行打开。
