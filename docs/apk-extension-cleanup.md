# APK 扩展精简与手杀武将合并

日期：2026-09-09。范围仅为用户列出的 33 个 APK 新增扩展；没有移除原有扩展、PXLNGU 成员或 AIoptimize。

## 当前结果

- 23 个无独立武将的工具/UI/特效/玩法扩展移出运行目录。
- 6 个武将来源的代码与素材实际收纳于 `apps/core/extension/手杀武将/apk/`，旧一级目录及注册项移除。
- 六个来源合计 62 个武将定义（含隐藏形态，不等于 62 名不同人物）。其中五个来源的 55 个定义参与增量合并；相同 ID 沿用已加载的工程定义，不覆盖。最终可选数量取决于原有包、启用开关及隐藏形态。
- “势魏延”的 7 个定义完整收纳但暂不运行。其旧代码修改玩家原型、全局音效，并依赖骨骼/UI 接口。为避免把兼容问题带入本体，没有用空函数伪装技能支持，也没有冒险改写使命技能。
- 假装无敌（含清瑶）、无名扩展、EpicFX、Thunder 保持独立。后两者包含武将且依赖旧 UI，因此保留完整代码素材，并在缺少 `decadeUI` 或 `dcdAnim` 时使用不执行原代码的说明入口。

开启“手杀武将”后，可分别调整五个可合并来源的开关，重启生效。迁移保留旧来源的开关；不强行开启原先关闭的“手杀武将”。若此前 APK 包默认关闭，需在手杀武将中自行打开对应来源。新浏览器在父扩展开启后默认启用这五个来源。

## 最小改动与保护

1. 原有手杀实现保留，仅入口增加组合加载。`base.js` 为合并前入口的逐字节副本。
2. “还原武将”的可选全局本体技能补丁不合入；只保留包内定义。其旧全屏特效分支不执行。
3. “8月武将补充”的两个辅助方法仅在不存在时添加。
4. 武将、技能、卡牌、翻译均采用已有定义优先；不复制已有功能来覆盖原实现。
5. 图片、音频和 CSS 的扩展路径改指向新子目录；二进制素材逐文件校验不变。APK 缺失的 `newsb_liubei.jpg` 使用本体现有 `sb_liubei.jpg`，不改变技能。
6. 旧启用开关和私有选项不删除。启动迁移只清理已退休名称，自动扫描和 URL 导入也不再恢复旧入口。
7. 未改动名将杀、活动武将等原有扩展源码；未进行用户存档清空或全局开关重置。
