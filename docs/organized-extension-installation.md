# 整理后扩展的工程安装与启用

## 本次安装结果（2026-09-09）

已把 `扩展包/整理结果/packages` 中全部 **49 个规范化扩展**安装到 `apps/core/extension/<扩展名>/`，对应整理清单中的 **474 个武将 ID**。这不是把原来的 300 多个文件强行全部启用；不支持、加密、冲突等原包的处理结果见 [整理核对报告](extension-organizer-audit.md)。

按照用户“暂不启用缺依赖的扩展”的选择，默认启用 **36 个扩展**，对应 **271 条武将定义**；另 **13 个扩展保留文件、默认关闭**。271 不代表相对本体净新增 271 名武将：例如手杀补全、强标包有少量 ID 与本体重合，本体加载器会按既有规则处理，并打印重复项提示。

“山海异志将包”需要的 `boss_modao`、`boss_guihuo`、`boss_guimei` 已从当前本体 `mode/boss.js` 的同名技能实现补入兼容层，仅在该扩展启用时注册，不覆盖已有技能，不启动挑战模式规则。

## 现在如何使用

1. 在项目根目录执行 `pnpm dev`（已经运行时无需重复启动）。
2. 打开 `http://127.0.0.1:8081/`，已有页面请刷新；修改正在进行的对局配置后需重新开局。
3. 进入身份模式，在菜单“扩展”中查看已登记的扩展，在“武将”中查看相应武将包。
4. 新浏览器存档会自动登记这 49 个扩展，并应用上述默认开关；以后手动关闭扩展不会因刷新又被打开。

这批登记不依赖“自动导入扩展”开关，也不需要再逐个导入 ZIP。原有“活动武将”“名将杀”等扩展的配置不会被这里修改。浏览器、主机名和端口不同，存档也可能不同；建议始终使用同一个访问地址。

已有存档会执行一次安全配置迁移，关闭名单内的扩展。之后若自行重新启用，刷新不会强行覆盖该选择；但在补全依赖并验证之前，不建议开启下表中的包。紧急禁用全部扩展的原有机制仍然优先。

## 后续增量安装

```powershell
pnpm extensions:organize
pnpm extensions:install
pnpm extensions:test
```

- 整理器仍只负责 `扩展包/整理结果`，安装命令才会写入工程目录。
- 安装前核对 ZIP 的 SHA-256；使用临时目录解压、检查安全路径、转换旧版 `game.import` 入口为当前工程需要的 ESM 导出，然后发布到正式目录。
- 已安装且来源相同的包逐文件校验，不重复覆盖。遇到同名不同版本或安装后被手工修改的文件会停止，避免损坏用户修改；这不是自动升级/卸载工具。
- 删除原始 ZIP 会影响整理结果，但不会自动卸载已经安装的扩展，也不会从工程登记清单中删除旧包。
- 安装清单 `apps/core/game/organized-extensions.json` 保存包名、武将 ID、ZIP 哈希和已安装文件哈希。它是运行登记和校验所需的数据，需要与资源一并提交。
- 后续新增包不自动获得本次验证结论，仍须验证技能依赖及对局，必要时加入关闭名单。只应安装可信来源的可执行扩展。

## 开发验证与限制

开发模式访问 `http://127.0.0.1:8081/?extensionCheck=1`，进入身份模式后，左下角可展开检查面板。它按安装清单核对启用包的武将、初始技能及递归 `group` / `inherit` 依赖，不改存档、不执行额外游戏操作。正常使用无需携带此参数；生产环境不显示该面板。

自动化测试覆盖整理器、安全路径、增量行为，以及首次登记、重复启动保留用户开关、安全配置迁移等场景。文件校验覆盖全部安装清单条目。

本次验证：20 项自动化测试通过；49 包文件哈希复核通过；身份模式下默认启用的 36 包、271 条武将定义均完成注册，初始技能及递归子技能依赖缺失数为 0。实机选择了“极●夏侯恩”，进入了身份对局并完成开局发牌，观察期间未出现浏览器控制台错误；存在原包未设置武将等级的回退提示和本体重名项日志。

这些检查不等于逐一穷举 474 名武将的所有技能组合。运行时动态拼接技能名、特定触发条件、其他模式、与原有扩展同时启用的兼容性及长期对局仍可能暴露原包问题。遇到问题请记录模式、武将、技能和第一条控制台错误，先关闭对应扩展后重启；不要用空技能掩盖错误。

## Git 提交边界

本次只修改本地工作区，没有创建提交或推送远程。扩展目录的 Git 白名单已加入这 49 个名称；需提交解压后的资源、登记/状态 JSON、兼容及登记代码、安装脚本、测试和文档。原始 ZIP、整理缓存、`node_modules`、构建输出、临时安装目录无需提交。

原包夹带的 5 个 `.bak` 备份已从安装校验清单排除，并由扩展目录的忽略规则排除在 Git 之外；现有本地备份保留，新安装时跳过。运行所需文件共 990 个，不包括这些备份。

仓库在包含这些修改的提交推送后，另一台电脑下载代码、安装依赖并按 [启动指南](how-to-start.md) 启动，即可自动登记这批扩展；不需要原始 ZIP 或本机浏览器存档。
